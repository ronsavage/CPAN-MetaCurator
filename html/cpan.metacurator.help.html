Running CPAN::MetaPackager's build.db.sh & then CPAN::MetaCurator's

Part 1: My Environment:

  • My web host and I use case-sensitive file systems. I use Debian.
  • The distro CPAN::MetaPackager ships with data/cpan.metapackager.sqlite (15Mb),
  • which is the output of running scripts/build.db.sh.
  • You will need your own copy of MetaCPAN's 02packages.details.txt.gz to re-run scripts/build.db.sh.
  • 02packages.details.txt.gz contains 9 header lines & about 270,458 records.
  • The distro CPAN::MetaCurator ships with data/cpan.metacurator.sqlite,
  • I am running SQLite V 3.46.1.

Part 2: CPAN::MetaPackager

Note: To minimise the load on CPAN, be really sure you wish to update cpan.metapackager.sqlite.

Specific steps:

  • Choose a download directory: cd ~/backup
  • Download it: wget https://www.cpan.org/modules/02packages.details.txt.gz
  • Unpack it: gunzip 02packages.details.txt.gz
  • Put it somewhere central: cp 02packages.details.txt /tmp

Q & A:

  • Q: Why did I download it into ~/backup before copying it to /tmp?
  • A: Because in ~/backup it will be preserved across a re-boot, whereas...
  • in /tmp it may not be. And yet CPAN::MetaPackager needs to be able to find...
  • the file on each user's machine. And for that a common directory name, /tmp, helps.

Run CPAN::MetaPackager's build.db.sh.

Specific steps:

  • Choose a download directory: cd ~/Downloads
  • Download CPAN-MetaPackager from MetaCPAN @ https://metacpan.org/dist/CPAN-MetaPackager
  • Unpack it: tar xvf CPAN-MetaPackager-1.04.tgz (or whatever the latest version is)
  • Move into the directory: cd CPAN-MetaPackager-1.04
  • The next command will take 190 minutes for 262,145 records on my Levono M70Q 'Tiny' desktop
  • Rebuild the db: time scripts/build.db.sh
  • This script looks for /tmp/02packages.details.txt, as mentioned above
  • The output is data/cpan.metapackager.sqlite

Part 3: CPAN::MetaCurator

Edit Perl.Wiki.html as desired, including updating para ChangeLog2.

Specific steps:

  • Load it into your web client: /home/ron/savage.net.au/misc/Perl.Wiki.html
  • Edit it
  • Save it by clicking on the red bullseye at the top right. This will save it in ~/Downloads
  • Export it as tiddlers.json thus:
  • In the 'Tools' tab click 'export all'
  • In the export menu click 'JSON format'. This exports to ~/Downloads/tiddlers.json

Run CPAN::MetaCurator's build.db.sh.

Specific steps:

  • If you wish, tell build.db.sh to use ~/Downloads/tiddlers.json via the env var INCLUDE_PACKAGES:
  • If you have /tmp/cpan.metapackager.sqlite available use INCLUDE_PACKAGES=1
  • Type: INCLUDE_PACKAGES=1
  • Type: echo $INCLUDE_PACKAGES
  • Type: export INCLUDE_PACKAGES
  • Choose a download directory: cd ~/Downloads
  • Download CPAN-MetaCurator from MetaCPAN @ https://metacpan.org/dist/CPAN-MetaCurator
  • Unpack it: tar xvf CPAN-MetaCrator-1.33.tgz (or whatever the latest version is)
  • Move into the directory: cd CPAN-MetaCurator-1.33
  • mv ~/Downloads/tiddlers.json data/
  • Rebuild the db: scripts/build.db.sh
  • The output is data/cpan.metacurator.sqlite
  • Export the db as a JS Tree: scripts/export.tree.sh
  • The output is html/cpan.metacurator.tree.html
